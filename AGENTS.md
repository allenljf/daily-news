# Daily News task entrypoint

Before starting work, read `CONTEXT.md`, `docs/requirements/daily-news.md`, and `docs/tasks/daily-news.md`.

Select one unfinished task whose dependencies are complete. Implement only that task, following its stated scope and verification. Run that verification, then check off the completed task steps and record the commands and result in its completion record.

For Flutter work, read `flutter-dev-guide/AGENTS.md` once it exists. For backend or mobile work, also follow the task-specific documents created for that area.
